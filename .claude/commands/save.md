---
description: 現在の変更をgitにコミットする
---

現在の作業ディレクトリの変更をgitにコミットしてください。手順:

1. `git status` と `git diff` で変更内容を確認する
2. 関連するファイルを `git add` でステージする(意図しないファイルは含めない)
3. 変更内容に基づいて、このリポジトリの過去のコミットメッセージ(`git log`)のスタイルに合わせた日本語のコミットメッセージを作成する
4. コミットを作成する(コミットメッセージの末尾に `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>` を付ける)
5. `git status` で結果を確認する

ステージされていない変更・追跡されていないファイルがない場合は、その旨を伝えて何もしない。
